# Spiele: jedes Jahr ein neues

Ein Spiel pro Lebensjahr meines Sohnes, gebaut von mir für ihn und gespielt mit uns beiden zusammen. Das erste ist für drei Jahre, das nächste kommt zum vierten Geburtstag. Jedes Spiel passt zu dem, was er in dem Alter kann und mag.

## Einleitung (Entwurf, wird später verfeinert)

Erscheint später auf der Seite `/spiele/` (siehe [threeyear.md](threeyear.md), Einbau).

Medienzeit für Kinder ist ein schwieriges Thema. Ganz verbieten möchte ich sie nicht, einfach laufen lassen auch nicht. Ich möchte meinen Sohn behutsam heranführen, so dass er sich damit auseinandersetzt, statt nur zu konsumieren.

Deshalb baue ich die Spiele selbst. Sie sind für ein Kind **zusammen mit einem Elternteil** gedacht: Das Kind steuert, der Erwachsene sitzt daneben, erzählt, liest die Geschichten vor und entscheidet, wann Schluss ist. Es gibt keine Werbung, keine Belohnungsschleifen, die zum Weiterspielen drängen, und keinen Zeitdruck. Zum Aufhören gibt es ein Ritual: Die Figur legt sich ins Bett, und die Welt wird dunkel.

Jedes Jahr kommt ein Spiel dazu, das zu seinem Alter passt.

## Gemeinsame Regeln für alle Spiele

- Für Kind und Elternteil zusammen. Was das Kind sehen soll, kommt ohne Text aus; Texte sind zum Vorlesen.
- Kein Scheitern, kein Fehlerton, keine Hektik. Jede Eingabe hat eine freundliche Wirkung.
- Läuft vollständig im Browser auf larmic.de (GitHub Pages). Spielstände bleiben lokal im Browser, nichts wird verschickt.
- Eigene Voxel-Grafik im Stil der Inselwelt ([Designsystem](../design-system.md)), nichts aus Minecraft oder Hytale.
- Es gelten die Regeln der Seite aus `CLAUDE.md`: keine externen Ressourcen, `prefers-reduced-motion`, der Text für Eltern ist ohne JavaScript lesbar.
- Idee: Ein Spielstand könnte im nächsten Jahr weiterleben. Deshalb ist das Speicherformat von Anfang an versioniert.

## Name der Reihe (offen)

„threeyear, fouryear, …“ ist der Arbeitstitel. Er macht klar, dass es pro Jahr ein Spiel gibt, klingt aber eher technisch. Vorschläge:

- **Jahresinseln**: passt zur Inselwelt der Seite; jedes Jahr kommt eine Insel dazu.
- **Mitwachsen**: betont, dass die Spiele mit dem Kind wachsen.
- **threeyear, fouryear, …**: bleibt beim Arbeitstitel.

Bis das entschieden ist, heißen Dateien und Code nach dem Arbeitstitel.

Idee dazu (Favorit des Vaters ist **Mitwachsen**): statt einzelner Spiele pro Jahr ein Spiel, das mitwächst. Jede Welt bekommt ein einstellbares Alter (im Menü für Eltern). Mit 3 laufen und Tiere treffen, mit 4 kommen z. B. Bauen und Abbauen dazu, mit 5 Aufgaben. Die Welt bleibt dieselbe, nur die Fähigkeiten wachsen. Technisch passt das: Die Regeln sind eine Zustandsmaschine, Fähigkeiten lassen sich je Alter freischalten, das Speicherformat ist versioniert.

Vor der Entscheidung prüfen, ob der Name als Marke eingetragen ist: [TMview](https://www.tmdn.org/tmview/) (EU und national) und [DPMAregister](https://register.dpma.de/), vor allem die Klassen 9 (Software), 28 (Spiele) und 41 (Unterhaltung). Eine kurze Websuche im November 2026 fand zu keinem der drei Vorschläge ein Spiel; das ersetzt keine Markenrecherche.
