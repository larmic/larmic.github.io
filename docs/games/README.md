# Mitwachsen: ein Spiel, das mitwächst

Ein Spiel für meinen Sohn, gebaut von mir und gespielt mit uns beiden zusammen. Es wächst mit ihm: Das erste Alter ist drei, mit jedem Geburtstag kommen neue Fähigkeiten dazu. Seine Welt bleibt dabei dieselbe.

## Einleitung (Entwurf, wird später verfeinert)

Erscheint später auf der Seite `/spiele/` (siehe [mitwachsen.md](mitwachsen.md), Einbau).

Medienzeit für Kinder ist ein schwieriges Thema. Ganz verbieten möchte ich sie nicht, einfach laufen lassen auch nicht. Ich möchte meinen Sohn behutsam heranführen, so dass er sich damit auseinandersetzt, statt nur zu konsumieren.

Deshalb baue ich das Spiel selbst. Es ist für ein Kind **zusammen mit einem Elternteil** gedacht: Das Kind steuert, der Erwachsene sitzt daneben, erzählt, liest die Geschichten vor und entscheidet, wann Schluss ist. Es gibt keine Werbung, keine Belohnungsschleifen, die zum Weiterspielen drängen, und keinen Zeitdruck. Zum Aufhören gibt es ein Ritual: Die Figur legt sich ins Bett, und die Welt wird dunkel.

Mit jedem Jahr wächst das Spiel mit: mehr Steuerung, mehr Geschichte, mehr eigene Entscheidungen.

## Altersstufen

Jede Welt hat ein Alter, das die Eltern im Menü einstellen. Das Alter schaltet Fähigkeiten frei; die Welt mit allem Erkundeten und allen entdeckten Tieren bleibt.

## Gemeinsame Regeln

- Für Kind und Elternteil zusammen. Was das Kind sehen soll, kommt ohne Text aus; Texte sind zum Vorlesen.
- Kein Scheitern, kein Fehlerton, keine Hektik. Jede Eingabe hat eine freundliche Wirkung, und schnelles Drücken lohnt nicht.
- Läuft vollständig im Browser auf larmic.de (GitHub Pages). Spielstände bleiben lokal im Browser, nichts wird verschickt.
- Eigene Voxel-Grafik im Stil der Inselwelt ([Designsystem](../design-system.md)), nichts aus Minecraft oder Hytale.
- Es gelten die Regeln der Seite aus `CLAUDE.md`: keine externen Ressourcen, `prefers-reduced-motion`, der Text für Eltern ist ohne JavaScript lesbar.
- Das Speicherformat ist versioniert; neue Altersstufen übernehmen bestehende Welten.
